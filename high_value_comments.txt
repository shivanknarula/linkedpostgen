Over the past few days, I worked on implementing a complete Learning from Demonstration (LfD) pipeline using ROS2 Humble, MoveIt 2, and Gazebo.

The goal was to enable a robot to learn a manipulation task from a demonstrated trajectory and then autonomously reproduce it in simulation.
🛠️ Key Features
✅ Gesture Recording & Playback
 ✅ Physics-Based Object Manipulation
 ✅ High-Level Task Orchestration
 ✅ ROS2 Service-Based Execution

🎯 Task
The robot learns and executes a trajectory to push a T-shaped object into a designated target zone.
⚙️ What I Implemented
GestureManager
Records robot joint trajectories
Saves demonstrations as YAML files
Replays learned gestures on demand
Task Orchestrator
Handles high-level task execution
Resets the simulation environment
Spawns a fresh object before every run
Triggers gesture playback automatically
🔬 Physics Tuning
To achieve stable object interaction, I configured the T-shaped object with:
Mass: 2.0 kg
Friction: 0.7
